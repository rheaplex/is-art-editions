Development
===========

Installation
------------
```
nvm install v19.3.0
nvm use v19.3.0
npm install -g truffle
npm install -g ganache
npm install -g local-web-server
npm install
```

Local
-----
```
# In different console session s
npm run ethnode
npm run develop
npm run serve
```
